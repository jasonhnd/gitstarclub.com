# Vendored asset fonts

The four static Geist font faces in this directory are vendored from Vercel's
[`geist-font`](https://github.com/vercel/geist-font) repository at commit
`10dc7658f13c38a474cde201bb09a4617267545b`.

The renderer loads only these byte-for-byte repository copies and never system
fonts. Their SHA-256 digests are:

- `Geist-Regular.ttf`: `85a1c6b18a6b0a06dfe9fd4f6d6a5d4979f74ec861eaef4bc7868b5492b8a117`
- `Geist-SemiBold.ttf`: `b9f52322d6d20a7ff1e7fe1310ff12ec851aebb83d24f8b4f1d4149298f489b2`
- `Geist-ExtraBold.ttf`: `68b974a40bb1a6dc76f00fe5e36a5fb58808bbafbc19e3c920e8dc51c13e75b3`
- `GeistMono-Medium.ttf`: `6fa6a795c17a11bcbef410f52a853e8503f8e25d92762d202d907c54f5c0c0fb`
