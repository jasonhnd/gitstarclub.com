# Issue 585: Next.js 16.3.6 and high-severity audit pins

## Goal

Clear the critical `next/og` ImageResponse advisory and the high `brace-expansion` and `undici` findings that fail `bun run audit:deps` on every pull request. Stop the repository share-image route from painting a URL path that did not resolve to a known repository.

## Scope

1. Pin `next` and `eslint-config-next` to 16.3.6 in `web/package.json`, and refresh `web/bun.lock`.
2. Raise the existing `web` overrides: `undici` to 7.29.1, and `brace-expansion` to 1.1.21, 2.1.7, and 5.0.12. Keep the 1.x and 2.x lines on their own major, because a global 5.x override breaks lint.
3. Pin `pipeline` `undici` to the patched 6.x release that `@vercel/blob`'s `^6.23.0` range can use, and refresh `pipeline/bun.lock`.
4. In the repository open-graph route, draw a repository name only when the path resolves to a known repository id and the stored entity is renderable. Otherwise return the site card. Cover that choice with a `web/lib` test.
5. Update the version sentences in `docs/FRONTEND.md`, `docs/SEO.md`, and `docs/TESTING.md`, plus an Unreleased changelog entry.
6. This plan.

## Out of scope

- Push to `main` or `pre`. Merge. Force-push. Deleting branches or files outside this issue.
- Wrangler write commands, Cloudflare or Vercel API calls, schedules, DNS, routes, or secrets.
- CI workflows, `.delivery.yml`, the Worker wrangler config, and deploy scripts.
- Ranking open-graph routes. Their labels come from ranking data, not from this repository path.
- The historical vinext check note in `docs/CF-MIGRATION-P3.md`, which records Next.js 16.3.5 on 2026-09-17.

## Acceptance

- `bun run audit:deps` exits 0 in `web/` and `pipeline/`.
- A known repository id produces a card model whose name is the stored `full_name`. A missing id, a missing entity, or a non-renderable stored name produces the generic card and does not carry the requested path.
- The AGENTS.md static job, including `audit:deps`, and the fixture production build pass on a fresh detached worktree.
- The pull request into `pre` reports `Closes #585`. Required GitHub checks `static` and `production-build` are green. This plan does not merge that pull request.
