# Data update notice

## Goal
Make the end of data updates clear to readers across the site.

## Scope
Add one accessible notice to the shared shell, translate it in all seven dictionaries, and test its placement and fallback.

## Out of scope
Data, rankings, refresh behavior, infrastructure, and issue 543.

## Acceptance
The notice appears once on English and localized routes, works at mobile and desktop widths, and retains dictionary parity. Focused tests and the full web suite provide supplementary verification; the required clean checkout and release review remain release gates.
